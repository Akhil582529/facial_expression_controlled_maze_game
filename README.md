# 🎮 Facial Expression Controlled Maze Game

This project is an interactive Python-based maze game that is controlled entirely through **facial expressions**. Using **OpenCV** and a **facial expression recognition model**, players can navigate through a maze without a keyboard or mouse — just by changing their expressions!

## 🧠 How It Works

- The game uses a webcam feed to detect your face in real time.
- A pre-trained expression recognition model classifies expressions (e.g., happy, sad, angry, surprised).
- Each facial expression maps to a specific movement (up, down, left, right).
- The player controls a character in a maze using only these expressions.

## 🛠 Tech Stack

- **Python**
- **OpenCV** – for face detection and real-time video processing
- **TensorFlow / Keras** – for the facial expression recognition model
- **Pygame** – to create the interactive maze game
- **NumPy** – for efficient array operations

## 📦 Features

- Real-time facial expression detection
- Fully playable maze controlled by face
- Smooth integration of camera input and game mechanics
- Fun and innovative hands-free interaction
- Modular code for easy updates and improvements
